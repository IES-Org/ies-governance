# IES Governance

Governance records, roadmaps, decisions, and administrative artefacts for the Information Exchange Standard (IES).

This repository is maintained by the IES Steering Group (SG).

## Repository Structure

- **roadmaps/** — Current and past IES roadmaps and strategic plans.
- **decisions/** — Formal Steering Group decisions and their rationale.
- **meeting-notes/** — Minutes and action logs from SG meetings.
- **policies/** — Governance processes, terms of reference, and procedures.
- **history/** — Project history, key milestones, and archival material.

## Contributing

This repository is managed by the Steering Group. If you wish to propose changes or additions, please open an issue or contact the SG chair.
