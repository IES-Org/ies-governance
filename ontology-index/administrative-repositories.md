# Administrative Repositories

This document records administrative repositories within the IES GitHub organisation.

Administrative repositories contain governance, management, planning, coordination, or informational material relating to IES. They do not contain ontology content and are not part of IES Top, IES Core, or any domain-driven ontology extension.

Administrative repositories may nevertheless be authoritative for the governance, operation, roadmap, communication, or management of IES.

---

## Purpose

The purpose of this document is to provide a clear index of administrative repositories and the area of IES activity they support.

It helps users and contributors identify:

* which administrative repositories exist
* what each repository is used for
* which group or function is responsible for each repository
* where repository-level documentation and maintainer information can be found
* how to find the relevant contact or contribution route

This document does not maintain a central list of Repository Maintainers. Repository Maintainer information is maintained in the relevant repository.

## Notes

* Administrative repositories do not contain ontology content.
* Administrative repositories may be authoritative for governance, management, planning, coordination, roadmap, communication, or release information.
* Repository-level maintainer information is maintained in the relevant repository.
* Administrative repositories should follow the mandatory repository structure expected across the IES GitHub organisation.
* Administrative repositories should make clear what they contain, who is responsible for them, and how changes are managed.
