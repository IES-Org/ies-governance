# Domain Repositories

This document records domain-driven repositories within the IES GitHub organisation.

Domain-driven repositories contain ontology content developed for a specific domain. They build from, extend, or align with IES Top and IES Core, and are governed directly by the relevant Domain Working Group.

---

## Purpose

The purpose of this document is to provide a clear index of domain-driven repositories and the domains responsible for them.

It helps users and contributors identify:

* which domain-driven repositories exist
* which Domain Working Group is responsible for each repository
* what each repository contains
* where repository-level documentation and maintainer information can be found
* how to find the relevant contact or contribution route

This document does not maintain a central list of Repository Maintainers. Repository Maintainer information is maintained in the relevant repository.

---

## Repository Naming

Domain-driven repositories should follow the IES repository naming convention.

Repository names should indicate the domain responsible for the repository. This helps users understand the relationship between a repository and the Domain Working Group responsible for its development and maintenance.

More information is available in:

* [Repository Naming](../processes/development/repository-naming.md)

## Notes

* Repository-level maintainer information is maintained in the relevant repository.
