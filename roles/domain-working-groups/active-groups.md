# Active Domain Working Groups

This document records the active Domain Working Groups within IES, the Information Exchange Standard.

Domain Working Groups lead domain-driven development and provide subject matter expertise for their respective domains.

Full Domain Working Group membership is not published centrally in this governance repository. Official role-holders are recorded separately in [Domain Working Group Official Role-Holders](./official-role-holders.md).

## Notes

* Each active Domain Working Group should have a defined domain scope.
* Each active Domain Working Group should have a Domain Working Group Chair.
* Each Domain Working Group Chair may appoint one Domain Working Group Representative.
* Domain Working Group Chairs and Domain Working Group Representatives are Voting Members of the Steering Group.
* Domain-driven repositories should be listed in the Ontology Index.
* Repository-level maintainer and contact information should be maintained in the relevant repository.
