# Current Platform and Communications Team

This document records the current Platform and Communications role-holders for IES.

Platform and Communications Management supports the operation of the IES GitHub organisation and communication around IES governance, development, and release activity.

This function includes the GitHub Organisation Custodian and any supporting Platform and Communications role-holders.

## Notes

* Platform and Communications role-holders are appointed by majority vote of the Steering Group.
* The GitHub Organisation Custodian is the primary role-holder for GitHub organisation administration.
* Elevated GitHub permissions must be limited to those who need them.
* Platform and Communications Management must include, or be supported by, an IES initiative member with the ability to support or secure funding for operational dependencies.
* If funding, access to funding, or operational continuity is at risk, the issue must be escalated to the Steering Group as a matter of urgency.
* Changes to Platform and Communications role-holders must be reflected in this document and, where relevant, in the Steering Group records.
