# Current IES Core Ontology Maintainers

This document records the current IES Core Ontology Maintainers for IES.

IES Core Ontology Maintainers are responsible for maintaining IES Core (Layer 1). They provide technical stewardship of the ontology layer that depends on IES Top and supports the IES domain extensions beneath it.

IES Core Ontology Maintainers are appointed by majority vote of the Steering Group.

## Notes

* IES Core Ontology Maintainers are responsible for maintaining IES Core.
* Maintainers appointed to IES Core share responsibility for its technical integrity and maintenance.
* Individual maintainers may take lead responsibility for particular areas of expertise, but this does not create exclusive ownership of any part of IES Core.
* Appointment as an IES Core Ontology Maintainer does not confer responsibility, authority or repository permissions for IES Top or any domain extension.
* IES Core Ontology Maintainers must carefully consider the downstream effects of proposed changes on IES domain extensions and any implications for IES Top.
* Where specialist assessment is required, maintainers should engage with the relevant IES Top Ontology Maintainers or domain-managed technical teams.
* IES Core Ontology Maintainers are appointed by majority vote of the Steering Group.
* Changes to IES Core Ontology Maintainers must be reflected in this document and, where relevant, in the Steering Group records.
